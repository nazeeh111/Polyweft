Payload mergeXYZ positions, UV corners and admitted material inputs. Everything else comes from the right scene. This is not a full-scene diff.

Review here. Write and verify with Blender.

  1. Prepare a common ancestor before branching:polyweft prepare model.blend --object Shell --output base.blend --blender /path/to/blender
  2. Save two edits in Blender, then capture:polyweft plan base.blend left.blend right.blend --output review --blender /path/to/blender
  3. Resolve conflicts and export decisions below. Apply into a fresh file:polyweft apply review --decisions decisions.json --output merged.blend --accept-payload-scope --blender /path/to/blender

The native command rechecks source hashes, recomputes the plan, saves a new file and reopens it. Exported decisions alone are not a merged Blender file. The browser preview uses triangulated faces for display and is not an artistic-quality check.
