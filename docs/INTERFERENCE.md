# Surface interference introduced by a merge

Independent vertex edits can combine cleanly as fields but create crossing surfaces. Inspection compares the same prepared polygon-index pair in ancestor, left, right and configured combined geometry. Each state uses its own actual Blender loop triangles, so a changed quad diagonal or concave polygon split is retained rather than replaced by browser triangulation.

`polyweft inspect REVIEW --decisions choices.json --output INSPECTION --blender EXE` verifies the plan, exact choices and source hashes; recaptures the sources; constructs the merged payload in memory; and writes a new read-only bundle. Source scenes are never saved during inspection. Ordinary native apply retains its separate save/reopen/no-clobber contract.

The classification concerns exact represented coordinates, not measurement tolerances. A spatial broadphase unions candidates across all four states, then exact rational triangle predicates retain crossings, coplanar overlaps, contacts and unknowns. Only intersections confined to an expected shared vertex or edge are treated as ordinary topological joins. Adjacent faces overlapping elsewhere remain detectable.

A pair is merge-only when the configured combined surface definitely crosses or overlaps and that interference is definitely absent in all three input states. Prior crossings, prior contact and unknown history are retained separately. Face witnesses include exact rational coordinates, native triangle indices, accepted whole vertex values, explicit choices and selected source hashes. These edits contribute to the witness surfaces; they are not a minimal causal vertex set. Complete branch comparisons change only displayed geometry, not merge decisions.

The model covers intersections between distinct target polygon faces in mesh coordinates. It does not inspect a single polygon folding across itself, other objects or shared instances, solid containment without surface intersection, evaluated modifiers, animation or physical clearance. Numerical geometry is not artistic intent or a safety certificate.

Inspection is bounded by 80,000 represented triangles per state, 100,000 broadphase visits, 20,000 candidate polygon pairs, 50,000 exact tests, 200 retained findings, eight witnesses per state/pair, 10,000 provenance entries, 15 seconds of analysis and a 32 MiB serialized report. Exhaustion and degenerate/omitted faces stay visible as incomplete/unknown. Positive witnesses can survive partial work; a partial zero count never establishes separation. Oversized serialized output is refused before publishing a bundle.

The studio verifies unchanged canonical report bytes against the report's SHA-256 identity, then checks source, choice, coordinate, face, corner and coverage consistency. It loads the recorded choices and immediately disables the inspection if a choice differs. Keep `inspection.json` unchanged; editing or reformatting its serialized content is refused. The checksum establishes integrity, not author identity or authenticity. Native CLI recapture remains the authoritative source check. Review plans can include local paths and labels; inspect them before sharing. The original release demos redact source paths.

Original Flanges has 16 prepared vertices, 24 triangular faces and 16 independent field edits. Its three inputs have no observed crossings, overlaps or contacts; the combined surface has 20 crossing face pairs. The supplied native merged file was saved and freshly reopened; its represented surface matches the inspection. Tide also exercises 224 quad faces and 448 native triangles with explicit vertex/UV/material choices. These are specific original cases, not universal correctness claims.

Intersection analysis has established alternatives, including Blender Mesh Analysis and 3D Print Toolbox. MeshGit is earlier mesh-merge research. Polyweft's addition is native four-state history and accepted-edit provenance bound to the same immutable merge decision, with a reproducible source-bearing example. It does not claim invention of mesh merging or collision detection.
